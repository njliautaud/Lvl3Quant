## 4. PIVOT PLAN

### Branch B1 (lead) — NQ instrument port
**Hypothesis**: Same CNN-Mamba architecture + same MBO methodology applied to NQ futures yields tradeable net edge. NQ has:
- Tick value: $5 (vs ES $12.50) — 2.5x more ticks per $ of move
- Spread: typically 1-2 ticks (vs ES 1 tick) — slightly worse
- Commission: roughly proportional in ticks at AMP — similar 0.4-0.6 ticks RT
- Volatility: roughly 1.5-2x ES on a tick basis

Net effect: the same +0.33 tick gross edge becomes 0.6-0.8 ticks gross on NQ tick scale. Above the cost floor. Tradeable.

**Steps**:
1. Probe Databento for NQ MBO data availability + cost (1 day)
2. Sync 60d of NQ MBO if available (1-2 days)
3. Run smart_v3 feature pipeline on NQ (uses existing code, 1 day)
4. Train fold-0 CNN-Mamba on NQ MBO events (~12 hr GPU)
5. Inference across OOT range, run through FIFO harness (1 day)
6. Verdict: FIFO net per cell, regime-skew check, viability gate per HC #494 R1

**Timeline**: 1-2 weeks to first FIFO verdict.

### Branch B2 (parallel) — Minute-bar timescale shift
**Hypothesis**: At 1-5 minute bars, typical ES move is 4-8 ticks. Commission becomes a rounding error. Predictability may be lower but cost ratio dramatically better.

**Steps**:
1. Resample existing ES MBO data to 1-min and 5-min bars (cheap)
2. Build minute-bar feature set (OFI windowed, vol regime, time-of-day, prior-period stats) — different from sub-second features
3. Train GBM or simple Transformer on minute-bar targets
4. FIFO-grade through canonical harness with hold horizons matching bar size
5. Viability check per HC #494 R1

**Timeline**: 2 weeks to first FIFO verdict.
